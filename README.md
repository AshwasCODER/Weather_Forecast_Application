# Weather_Forecast_Application
The Weather Forecast Application is a modern web app built using JavaScript, HTML, and Tailwind CSS that provides real-time weather updates for any city around the world. By leveraging the OpenWeatherMap API, the app allows users to search for weather details by city name or by using their current location

# 🌦️ Weather Forecast Application

A weather forecast app built using **JavaScript**, **HTML**, and **Tailwind CSS** that fetches real-time data from the **OpenWeatherMap API**.

## 🚀 Features

- Search weather by **city name**
- Get weather using **current location**
- View **current temperature, wind speed, humidity**
- View a **5-day forecast**
- **Recent search** dropdown (localStorage)
- Responsive for Desktop, Tablet, and Mobile
- Graceful error handling

## 📦 Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- OpenWeatherMap API

## 🛠️ Setup Instructions

1. Clone the repository
2. Get a free API key from [https://openweathermap.org/](https://openweathermap.org/)
3. Replace `YOUR_API_KEY_HERE` in `script.js` with your API key
4. Open `index.html` in a browser
